## Authority

- **ZEN is the authority** for every decision. Its values come from the versioned catalogue JSON (`docs/saral/rule_catalogue.v2.json`) and are *authoritative (prototype_synthetic, pending approval)*.
- **Bajaj numbers retrieved by RAG are indicative public guidance** (user, 2026-11-03 23:07 IST). ZEN floors are **not forced** to equal them; where they differ, the difference is listed below and the agent says the published figure is general guidance and the assessment decides.
- Stricter band and grade rules (PL-119..PL-125) stay internal and are never stated as a minimum.

## No duplication

1. **Single source of truth.** Rules and thresholds exist only in the catalogue JSON. Docs are generated from it.
2. **RAG never indexes ZEN.** The catalogue, data dictionary, `THRESHOLD_APPROVALS.md`, `ZEN_DESIGN.md`, product matrix and any prototype threshold are excluded from every collection. RAG indexes only `saral_nbfc_policy` (Bajaj) and `rbi_regulatory` (RBI).
3. **Decision reasons come from the stored decision.** The agent reads the decision via its tool (rule hits -> `borrower_reason_category` -> message, per [REASON_DISCLOSURE_POLICY.md](REASON_DISCLOSURE_POLICY.md)), never via RAG.
4. **No vector search over rules.** An underwriter lookup is an exact lookup by `rule_id` in the JSON.
5. RAG may explain *general* terms (what FOIR is, what Bajaj publishes) and must label the figures as indicative.

## Recommended retrieval metadata

Add to every chunk that states an eligibility number (the chunks above, plus BFL-PL-OVERVIEW#005, #021, BFL-PL-ELIG-DOCS#000, BFL-PL-SALARIED#004, BFL-INSIGHT-REJECTION#007):

```json
{"authority": "indicative", "topic": "eligibility", "zen_authoritative": true,
 "agent_instruction": "Published guidance only; the Saral assessment decides. Do not present as the applicant's threshold."}
```

Chunks without an eligibility number keep `authority: "informational"`. RBI chunks keep `authority: "regulatory"`. This is a recommendation for the corpus owner; the corpus was not changed here.
