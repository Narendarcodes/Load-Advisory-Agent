- **APPROVED_REGULATORY**: an RBI chunk states the requirement (id cited).
- **APPROVED_OWNER_DECISION**: an extension for the product list the user confirmed at 23:03 IST. He should accept or rename it.
- **PENDING_BUSINESS_APPROVAL**: the value is an `A-NN` row in [THRESHOLD_APPROVALS.md](THRESHOLD_APPROVALS.md).
- **PROTOTYPE_SYNTHETIC**: every other value (v2 proposal, new Hark proposal, or a band/grade value from the 22:53 directive). Test profile only. **No invented value is Bajaj policy.**

A rule's status is the least-approved status among its parameters. A DECLINE on a rule that is not approved is active only in `prototype_synthetic`, with `not_for_live_use = true`.

## Decision aggregation

Precedence: **DECLINE > MANUAL_REVIEW > MORE_INFORMATION_REQUIRED > ELIGIBILITY_CONDITIONS_MET**. Rule outcomes are PASS / FAIL / REVIEW / INSUFFICIENT_DATA.

- Risk indicators must not automatically become hard declines.
- Missing inputs must not be treated as failed inputs.
- Hard-decline rules require explicit policy approval.
- Manual review must override automatic positive outcomes.
- Every outcome must include rule IDs and explanations.
- Eligibility conditions met does not mean loan sanctioned.
- A DECLINE resting on a low-confidence (OCR-derived) value becomes MANUAL_REVIEW.
- A risk-signal rule (risk_signal=true) can only produce MANUAL_REVIEW and the generic borrower category DETAILS_NOT_VERIFIED.
- A rule whose mvp_status is DEFERRED is not evaluated in the MVP; it is kept in the catalogue.
- The offer step (PL-125) runs after the gates. DECLINE from a gate wins; under MANUAL_REVIEW the offer is indicative for the underwriter.
- ELIGIBILITY_CONDITIONS_MET with eligible_amount < requested_amount is reported as COUNTER_OFFER; it is not a sanction.

Band rules are stricter checks *on top of* the public guidance. They are internal: they REVIEW or size the offer down, they are never told to the borrower as a minimum, and PL-029 stays the only score decline.

|---|---|---|---|---|

| B | score >= 700 and no DPD in 12 months | 20 | 0.5 | Rs. 25,00,000 |
| C | score >= 650 and max DPD <= 30 in 12 months | 15 | 0.45 | Rs. 10,00,000 |
| NTC | no bureau hit | 8 | 0.4 | Rs. 2,00,000 (A-22) |

**Offer formula (PL-125, deterministic):**

```
max_emi        = grade_foir_cap x monthly_net_income - (existing_monthly_obligations + other_monthly_obligations)
foir_principal = max_emi x ((1+r)^n - 1) / (r (1+r)^n),  r = 0.20/12 (A-05), n = requested tenure
eligible       = floor_1000( min(requested, product_cap, grade_amount_cap, grade_multiple x monthly_net_income, foir_principal) )
if eligible < requested: recompute foir_principal with n = product max tenure; keep the larger eligible
APPROVED       if eligible >= requested at the requested tenure
COUNTER_OFFER  if eligible >= requested only at a longer tenure, or 40,000 <= eligible < requested
DECLINE        if eligible < 40,000 (Bajaj minimum, BFL-PL-OVERVIEW#003)
output: offer_outcome, eligible_amount, offer_emi, offer_tenure_months, binding_cap, internal_reason
```
